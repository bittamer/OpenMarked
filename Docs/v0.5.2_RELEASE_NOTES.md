# OpenMarked 0.5.2

OpenMarked 0.5.2, build 8, is a performance, safety, and maintainability release. It preserves the 0.5.1 user-visible behavior while removing repeated document scans, repeated file and bundle reads, repeated SwiftUI recomputation, and duplicated test coverage.

## Highlights

- Adds a shared rendered HTML index so render diagnostics, inspection, image handling, export, remote-image blocking, and performance profiling reuse one parsed view of the rendered HTML.
- Replaces full cross-document Markdown rendering for heading-link validation with heading-only scanning.
- Caches rich-content assets, user preview themes, app chrome themes, resolved colors, and palette conversions.
- Strengthens preview HTML sanitization against obfuscated script URLs, unsafe data URLs, event handlers, scripts, and unsafe URL-bearing attributes.
- Reuses document title, front matter, and Markdown heading scanner work instead of rescanning common document metadata.
- Extracts preview helper JavaScript into a bundled resource and reuses preview search matches for same-query next and previous navigation.
- Reduces outline and inspector SwiftUI recomputation with lazy outline rows, local filtered list reuse, and shared diagnostic display metadata.
- Caches window state persistence in memory so saves no longer decode the whole persisted dictionary before writing.
- Deduplicates the test suite around Swift Testing, removing 1,531 lines of duplicated test code while preserving coverage.

## Performance Audit

The final audit used the packaged `dist/OpenMarked-0.5.2/OpenMarked.app` with the generated large-image fixture:

- Scroll-time CPU peak: `5.9%`
- Post-settle CPU: `0.0%`
- Post-settle RSS: `522,304 KB`
- Repeated status statistics hot-stack matches: `0`
- Repeated preview theme CSS hot-stack matches: `0`

The post-settle sample remained idle with no OpenMarked hot work in the sampled stacks.

## Known Limitations

- Render-changing edits still reload the full WebView document; DOM patching remains deferred.
- HTML/PDF export and print continue to use original local assets by default.
- Opening the same source file more than once may create duplicate tabs.
- Exact native tab order and tab group topology are not restored.
- Developer ID signing and notarized public distribution require Apple credentials.
