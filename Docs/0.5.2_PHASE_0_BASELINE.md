## Regression Gates For Later Phases

Every implementation phase after Phase 0 must pass:

```sh
swift test
swift run OpenMarkedVerifier
Scripts/verify_visual_snapshots.sh
Scripts/verify_export_artifacts.sh
Scripts/performance_scroll_audit.sh
```

Later phases should compare against this baseline and must not reintroduce:

- Status bar statistics recalculation in scroll-time hot stacks.
- Preview theme CSS reloads in scroll-time hot stacks.
- Non-zero idle CPU after the scroll settle window.
- Missing visual snapshot cases.
- Missing export artifact cases.

## Notes

- Phase 0 did not add new benchmark infrastructure because the existing verifier, snapshotter, export checker, and scroll audit already cover the required baseline surfaces.
- Performance numbers are local-machine baselines, not cross-machine release guarantees.
- The scroll audit remains the primary regression check for the previous `0.5.1` performance fixes while `0.5.2` optimisation work proceeds.
